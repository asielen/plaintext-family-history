# Sending Me Documents and Photos

Thank you for sharing family material. Every scan, photo and document helps fill in gaps in our family history. You don't need to install anything or learn any software: just a file browser, a text editor (Notepad or TextEdit, not Word) and email.

I'll send you a zip with an `inbox` folder. Unzip it. Inside is a file called `_TEMPLATE.notes.md`, the notes template you'll copy and fill in below.

---

## What you can send

Anything you think might be useful: a photo of a relative, a house or a grave; a scan of a letter, certificate or clipping; a screenshot from a genealogy site; even just a note ("I remember hearing that…"). If you're not sure whether to send something, send it.

---

## Two ways to send it

### Method A: a file plus a notes file (preferred)

Drop your file into the `inbox` folder. If you can, add a notes file describing it. **The notes file has the same name as the file it describes, with `.notes.md` on the end in place of the original ending.** One notes file per item.

For example, for a scan of Ben's birth certificate:

```
bens_birth_certificate.pdf          ← the scan
bens_birth_certificate.notes.md     ← a copy of _TEMPLATE.notes.md, renamed to match
```

To make the notes file, copy `_TEMPLATE.notes.md`, rename the copy to match your file (for example `bens_birth_certificate.notes.md`), open it, and answer the questions in your own words.

Sending a file with **no** notes is fine too; I'll still take it. For your most important items, the notes help a lot.

### Method B: one folder per item

If something has several parts that belong together (a photo with writing on the back, or a recording with a transcript), make a folder for it, put all the parts in, and add **one** notes file named exactly `notes.md` (a copy of the template).

Everything in a folder is treated as **one item**, so use a separate folder for each unrelated thing.

If a record is in another language and you have an English version, include both in the same folder, and the translation will be filed beside the original. Don't change the original's wording; the translation is kept as a separate file.

```
grandma-rose-portrait/
├── front.jpg
├── back.jpg
└── notes.md          ← a copy of _TEMPLATE.notes.md, renamed to notes.md
```

---

### Method C: email

On the family website, each person's page has a "Tell me what you know" link. It starts an email with the right name already in it. Answer the questions in your own words, attach any photos, and send it. You don't need the inbox folder for this.

---

## Send it back

Zip the `inbox` folder back up (Windows: right-click, then "Send to", then "Compressed folder"; Mac: right-click, then "Compress") and email it to me.

I'll look at what you sent and add it to the archive. Anything you wrote in a note becomes a *suggestion* I review. Nothing becomes a permanent record until I accept it, and I'll follow up if I have questions.
