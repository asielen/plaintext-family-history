# Privacy & Example-Data Policy

This repository is the public **spec and tooling** for Plaintext. It must never contain real, private family-history data.

- **Examples are fictional.** Use the Hartley family in `example-archive/`, or invent placeholders. Never use a real person's records.
- **No data about living people** anywhere: issues, pull requests, test fixtures or docs.
- **No DNA files, raw genealogy exports, personal photos or identifiable family documents.**
- **Anonymize real situations.** If an issue needs a real research situation to make sense, change the names, places, dates and IDs first.
- **Your own archive is separate and private.** You create your real family archive with `fha install`, in its own folder and, if you use git, its own *private* repository. See "Your archive and this repo" in the root `README.md`. Your archive uses the tools in this public repo; your data never goes into it.
- Maintainers may delete any issue, comment or pull request that exposes personal data.

The public repo holds the format and the general-purpose tools; family data lives only in each person's private archive.
