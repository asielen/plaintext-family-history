# CLAUDE.md

Read and follow **AGENTS.md**. It is the operating instruction for any AI agent in this archive (Codex and other agents read it directly), and it applies to you in full.
In **tool-building** or **code-review** mode, also read **[AGENTS_TOOLING.md](https://github.com/asielen/plaintext-family-history/blob/master/AGENTS_TOOLING.md)**. That doc and the `TOOLING_*.md` docs named below live in the **project repo**; an installed archive does not carry them (TOOLING §13c), because building the tools is a workshop-clone activity. Inside an archive, those two modes do not apply.
