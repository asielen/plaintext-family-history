# Notes about this item

Drop new scans, photos and downloads in this `inbox/` folder until you're ready to turn them into a source. Beside each one you can leave a note like this so you remember what it is. Copy this file and rename the copy to match the item, with `.notes.md` on the end (for "grandmas photo.jpg", call it "grandmas photo.notes.md"). No format is required; plain sentences are fine.
